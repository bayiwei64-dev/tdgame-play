# 村庄保卫战 · 浏览器试玩

电脑打开 https://bayiwei64-dev.github.io/tdgame-play/ ，点击“开始试玩”，无需下载或安装。

WASD 移动，J 攻击，K 能量技能，Q 时间停止；在空地按住鼠标，移到塔的选项后松开建造。
时间停止持续 5 秒，冷却从施放起计算 10 秒。停止期间玩家仍可移动、攻击并造成伤害。
切出页面自动暂停，也可按 Escape 暂停。页面可控制声音或重新开始。
